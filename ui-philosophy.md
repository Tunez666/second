🌳 LifeTree Design System
Философия проекта

LifeTree — это не корпоративная CRM.

Не система управления бизнесом.

Не очередной клон Notion.

LifeTree — это личное пространство человека.

Место, куда он приходит не потому, что обязан работать, а потому что хочет заниматься своими проектами, учёбой, хобби или просто привести мысли в порядок.

Интерфейс не должен бороться за внимание пользователя.

Он должен стать спокойным фоном, который помогает сосредоточиться.

После открытия сайта человек должен чувствовать примерно следующее:

"Я дома. Можно спокойно продолжить то, чем занимался."

Если через несколько минут пользователь перестаёт замечать интерфейс и думает только о своих задачах — дизайн выполняет свою работу.

Атмосфера

У каждой темы есть своё настроение.

☀ Светлая тема

Ассоциация — спокойное утро.

Не ослепительно белый офис.

Не стерильная лаборатория.

А мягкий дневной свет из окна.

Поэтому используются:

тёплый почти белый фон;
лёгкие зелёные оттенки;
мягкие границы;
низкий контраст;
большое количество воздуха между элементами.

Интерфейс должен выглядеть живым и естественным.

🌙 Тёмная тема

Ассоциация — тихий вечер.

Это не классический Dark Mode.

Не OLED.

Не абсолютно чёрный фон.

Это ощущение комнаты вечером, когда включена настольная лампа и хочется ещё немного поработать над своим проектом.

Используются:

тёплый тёмный фон;
спокойные зелёно-серые поверхности;
мягкие светлые тексты;
приглушённый шалфейный акцент.

Тёмная тема должна расслаблять глаза, а не поражать контрастом.

Основной принцип

Интерфейс никогда не должен утомлять.

Любое решение проверяется одним вопросом:

Смогу ли я провести здесь несколько часов подряд?

Если ответ "нет", значит дизайн слишком агрессивный.

Цветовая философия

Главный цвет проекта — шалфейный зелёный.

Он символизирует:

рост;
развитие;
спокойствие;
жизнь.

При этом он никогда не должен быть ярким.

LifeTree не про экологию.

И не про природу.

Дерево — это лишь метафора личного роста человека.

Использование акцентного цвета

Акцент применяется только там, где действительно необходимо привлечь внимание.

Например:

основные кнопки;
активные пункты меню;
ссылки;
элементы в фокусе;
небольшие декоративные детали.

Если пользователь видит слишком много зелёного — значит его уже слишком много.

Акцент должен оставаться акцентом.

Карточки

Карточки — основной строительный элемент интерфейса.

Практически всё содержимое сайта строится из карточек.

Каждая карточка должна:

быть немного светлее или темнее основного фона;
иметь мягкую границу;
иметь большие радиусы;
использовать минимальную тень.

Тень существует только для разделения слоёв.

Никогда — для создания ощущения "парящих" элементов.

Формы

Формы должны быть максимально простыми.

Поля ввода:

большие;
удобные;
хорошо читаемые;
без лишнего декора.

Фокус поля должен ощущаться мягко.

Без ярких синих рамок.

Кнопки

Кнопки должны выглядеть спокойно.

Без градиентов.

Без стеклянных эффектов.

Без сложных теней.

Hover лишь слегка меняет оттенок.

Кнопка не должна "кричать":

"Нажми меня!"

Она должна спокойно говорить:

"Когда будешь готов."

Анимации

Все анимации должны быть почти незаметными.

Обычно достаточно:

transition: .2s ease;

Допускаются:

небольшое изменение цвета;
изменение тени;
смещение на 2–3 px.

Не используются:

bounce;
вращения;
резкое масштабирование;
долгие анимации;
чрезмерные эффекты.

Если пользователь замечает анимацию сильнее, чем контент — она слишком активная.

Радиусы

LifeTree использует большие радиусы.

Причина проста:

Большие радиусы делают интерфейс дружелюбнее.

Острые углы создают ощущение строгости.

Закругления создают ощущение спокойствия.

Практически все элементы используют единый набор радиусов через CSS-переменные.

Типографика

Текст — самый важный элемент интерфейса.

Поэтому:

крупные заголовки;
комфортная высота строки;
спокойные вторичные цвета;
никаких декоративных шрифтов.

Текст должен читаться легко даже после нескольких часов работы.

Иконки

Иконки должны быть:

простыми;
минималистичными;
одного визуального стиля;
без лишней детализации.

Иконка лишь помогает быстрее ориентироваться.

Она не является украшением страницы.

Пространство

Воздух — часть дизайна.

Лучше оставить немного пустого места, чем пытаться заполнить каждый пиксель.

Свободное пространство снижает визуальный шум и помогает сосредоточиться.

Цвета состояний

Цвета системных сообщений никогда не меняются между темами.

Это формирует привычку пользователя.

Всегда используются:

🟢 успех — зелёный;
🔴 ошибка — красный;
🟠 предупреждение — оранжевый;
🔵 информация — синий.
Что нельзя делать

При разработке новых страниц избегать:

кислотных цветов;
чисто белого фона;
абсолютно чёрного фона;
чрезмерных теней;
резких контрастов;
перегруженных экранов;
сложных анимаций;
большого количества разных акцентных цветов;
элементов, которые отвлекают от содержимого.
Главный критерий

Перед тем как считать экран готовым, нужно задать себе один вопрос:

Если бы этим приложением пользовался я каждый день по несколько часов, было бы мне в нём спокойно?

Если ответ — да, значит дизайн соответствует философии LifeTree.
